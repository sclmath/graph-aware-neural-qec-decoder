# Graph-Aware Neural QEC Decoder

## 1. 项目概述

构建面向表面码、量子 LDPC 码和 HGP 码的图感知混合解码器。项目将量子纠错解码建模为带噪声图上的推断与组合优化问题，结合置信传播、匹配或 OSD，以及图神经网络，研究逻辑错误率、解码延迟和内存占用之间的权衡。

## 2. 研究问题

1. 如何把 decoder error model 和 Tanner 图结构编码为适合图神经网络处理的特征？
2. 学习到的边权重和候选误差集能否减少 BP 迭代次数与 OSD 搜索规模？
3. 混合解码器能否在不同噪声率、码距和码族之间保持稳健？
4. 神经网络推理的 GPU 加速是否能在可接受的精度下降低单 shot 延迟？
5. HGP 码与表面码的图结构差异如何影响解码器的泛化能力？

## 3. 研究范围

### 3.1 纠错码

- Repetition code
- Rotated surface code：d=3、5、7，扩展目标为 d=9
- 小型 HGP 码
- 结构化量子 LDPC 码及其 Tanner 图
- 不同基矩阵生成的 HGP 码族

### 3.2 噪声模型

- Code-capacity noise
- Circuit-level depolarizing noise
- Detector error model
- 噪声率扫描：0.001、0.002、0.003、0.005、0.008、0.01
- 训练集与测试集之间的噪声率偏差
- 测量错误和跨轮次关联

### 3.3 技术栈

- Python
- Stim：量子线路采样和 detector error model
- PyMatching：MWPM 基线
- PyTorch：GNN、时序模型和多任务训练
- 支持 BP+OSD 的量子 LDPC 解码库
- NumPy、SciPy、Matplotlib、pandas
- CPU/GPU profiling 工具

## 4. 输入表示

每个解码样本表示为检测事件图或 Tanner 图：

- 节点：detector event、check node 或 stabilizer measurement
- 边：可能的 error mechanism
- 节点特征：syndrome bit、时间坐标、测量类型、check 类型
- 边特征：错误概率、空间距离、时间距离、error type、所属 stabilizer
- 全局特征：code distance、物理噪声率、线路深度、码族
- 时序特征：最近若干轮 syndrome history

## 5. 模型方案

### 5.1 保守混合架构

`BP -> GNN 边权重重估 -> BP 重跑 -> OSD 后处理`

该方案保留 syndrome 一致性约束，避免纯神经网络输出无效 correction。

### 5.2 图编码器

- 使用消息传递网络编码 detector graph 或 Tanner graph
- 学习 error mechanism 的可靠性分数
- 输出候选误差集和边权重
- 探索局部感受野与可扩展性设计

### 5.3 时序编码器

- 使用一维卷积或轻量 Transformer 处理 syndrome history
- 建模测量错误和跨轮次关联
- 控制序列长度以避免推理延迟过高

### 5.4 解码输出

- 逻辑 observable parity 预测
- 候选误差机制排序
- 根据候选集合运行 BP+OSD 或小规模组合优化
- 输出最终 correction 和置信度
- 保证输出满足 syndrome 约束

## 6. 训练目标

采用多任务损失：

- 错误机制预测：二分类交叉熵
- 逻辑翻转预测：observable parity 分类
- BP 收敛预测：判断是否需要进入 OSD
- 候选排序：learning to rank
- 稀疏性正则：限制 OSD 候选规模

训练数据必须按随机种子、噪声率、码距和码族进行切分，严格避免测试信息泄漏。

### M3：混合解码器与失效边界（已完成）

同分布 headline（repetition d=3，circuit-level p=0.01，32768 shots）：

| decoder | logical errors | LER | s.e. | syndrome 一致 | 收敛率 | 平均迭代 | µs/shot |
|---|---:|---:|---:|---:|---:|---:|---:|
| mwpm | 217 | **0.00662** | 0.00045 | - | - | - | 0.1 |
| bp | 309 | 0.00943 | 0.00053 | 0.9899 | 0.9899 | 0.707 | 1.9 |
| bp_osd | 331 | 0.01010 | 0.00055 | 1.0000 | 0.9899 | 0.707 | 4.0 |
| bp_gnn | 312 | 0.00952 | 0.00054 | 0.9912 | 0.9912 | 0.557 | 1.8 |
| bp_gnn_osd | 333 | 0.01016 | 0.00055 | 1.0000 | 0.9912 | 0.557 | 2.6 |
| bp_gnn_osd_learned_order | 317 | 0.00967 | 0.00054 | 1.0000 | 0.9912 | 0.557 | 3.0 |
| osd_gnn | 319 | 0.00974 | 0.00054 | 1.0000 | 0.9899 | 0.707 | 135.1 |

结论与边界：

1. **d=3 repetition 上学习先验无显著收益**（`bp` 0.00943 vs `bp_gnn` 0.00952，McNemar z=-0.77，p=0.44），但平均迭代从 0.707 降到 0.557；**2026-10-16 已补到 3 seeds / 98304 shots**：配对 ΔLER = +0.00009 / −0.00098 / +0.00003（均值 **−0.00028 ± 0.00035**，符号翻转），`mwpm` 相对 `bp_gnn` 稳定领先 +0.00288 ± 0.00034（见 `results/m2/HEADLINE_MULTISEED.md`）；
2. **OSD-0 回退换不来免费的 syndrome 一致**：在 288 个未收敛 shot 上 67 修好 / 88 弄坏（z=-1.69，p=0.092），且不存在「只救不伤」的触发阈值，只有一条陡峭的 LER–一致性 Pareto 前沿；**该负结果已在 T8 得到正面出口**——换成 OSD-CS（候选组合扫描）后，同一 288 个 shot 上 OSD 回退从「154→175 弄坏」变成「154→91 修好」，见 `docs/T8_OSD_CANDIDATE_SET.md`；
3. **把 OSD 排序换成学习 logits 有正收益**（`bp_gnn_osd` 0.01016 vs `bp_gnn_osd_learned_order` 0.00967，z=+2.26，p=0.024）；
4. **强度自标定**：在目标分布验证集上重选先验插值强度，最优值落在 0.75-1.00，扫描曲线平坦（d=3 上收益本身很小）；
5. **跨码距迁移有效**：d=3 训练的模型直接用于 d=5，`bp` 0.05078 → `bp_gnn` **0.01709（-66%）**，机制后验 AUC 0.9876；
6. 机制后验在噪声偏移下保持校准：AUC 0.973-0.998，log loss 始终低于 DEM 先验。
- 产出：`results/m3/`、`docs/M3_HYBRID_DECODER.md`

### M4：旋转表面码与 HGP（已完成）

- **旋转表面码支持**：`rotated_surface_code` 家族下 MWPM / Union-Find / BP / BP+OSD / BP+GNN 全链路可用
- **小型 HGP 码构造**：`src/graph_qec/codes/hgp.py`（Tillich-Zémor 超图积、辛配对逻辑算符基、code-capacity DEM、检测器坐标嵌入），两个码 [[13,1,3]] 与 [[58,16,3]]
- **图结构对比**：线路级表面码 DEM 是稠密超图（d=3/d=5 的 check 度最大 48/80，平均 23.5/41.7，4-圈 1956/26046）；HGP 不可匹配（`matchable=False`），MWPM / Union-Find 对其完全不可用
- **学习重加权的跨码族表现**：
  - 表面码 d=3 线路级 p=0.005：**3 seeds 复核 0.04149 → 0.02945（-29.0% ± 2.4%）**，平均迭代 -40%，单 shot 延迟 1.85× 更快（单 seed 曾给 -18.2%，是三个 seed 里最小的；`results/m4_surface/D3_MULTISEED.md`）
  - 表面码 d=5 线路级 p=0.005：**3 seeds 复核 0.10376 → 0.06527（-37%，标准误 0.0005/0.0026）**，平均迭代 -43%，单 shot 延迟 1.78× 更快
  - 表面码 d=7 线路级 p=0.005：**3 seeds 复核 0.24056 → 0.18009（-25%，标准误 0.0024/0.0085）**；BP 收敛率仅 0.12、平均迭代 28.9/32，学习先验把收敛率提到 0.17-0.30 但收益**回落**——增益与码距的关系是 **d=3 −29.0% → d=5 −37.1% → d=7 −25.1% 的先升后降**，不是单调增长
  - HGP [[13,1,3]] p=0.05：`bp` 0.03601 → `bp_gnn` 0.03491（-3%），迭代 -30%；**3 seeds 复核为 −3.1% / −5.9% / −9.7%**（同号，效应小）
  - HGP 跨尺寸迁移（[[13,1,3]] → [[58,16,3]]）：**单 seed 的 −11% 不复现**——3 个模型 seed 为 −11.4% / +4.9% / +12.5%，均值 **+2.0% ± 7.1%**（32768 shots/seed）→ **无稳健收益**；同一目标码上自训练可达 −27%（`bp` 0.39487 → `bp_gnn` 0.28638）
  - 表面码 d=3 → d=5（码容量 p=0.05）：`bp` 0.13806 → `bp_gnn` 0.12152（-12%）**（单 seed，未做多种子复核）**
  - 规律（2026-10-16 用 3 seeds 修正）：**收益在 BP 强度"中等"时最大，两侧都缩小**
    - 码距轴（p=0.005，3 seeds）：d=3 **−29.0% ± 2.4%** → d=5 **−37.1%** → d=7 −25.1%（非单调，峰值 d=5）
    - 噪声率轴（5 个噪声率，30 点全网格）：d=5 **−37.4% → −43.4% → −37.1% → −32.8% → −25.4%**（p=0.002→0.01，**峰值在 p=0.003，出现低端拐点**）；d=7 **−38.2% → −32.6% → −25.1% → −13.4% → −9.9%**（单调下降，峰值落在区间下沿 p=0.002）
    - 因此"BP 越弱收益越大"只是**码距轴**上的现象，不能外推到噪声率轴；BP 接近最优（d=3）或退化到局部推断失效（d=7、高 p）时收益都会塌缩

### T8：OSD 候选集学习（已完成 OSD-CS 部分）

把 OSD 后处理从 OSD-0 换成 **OSD-CS(λ)**（对 λ 个最不可靠的非 pivot 列枚举全部子集，按软权重取最优）：

| 配置（32768 shots） | bp | OSD-0 | OSD-CS | bp+GNN | bp+GNN+OSD-CS | mwpm |
|---|---:|---:|---:|---:|---:|---:|
| repetition d=3 电路级 p=0.01 | 0.00943 | 0.01010 | **0.00754** (λ=4) | 0.00952 | **0.00760** | 0.00662 |
| 表面码 d=3 电路级 p=0.005 | 0.04007 | 0.04315 | **0.02505** (λ=8) | 0.03455 | **0.01913** | 0.01694 |

- OSD-0 在两个配置上都**有害**（z=-1.73 / -3.19），OSD-CS 把它变成**显著有益**：表面码 -37%（`bp`）/ -53%（相对 OSD-0）；`bp_gnn_osd_cs8` 距 MWPM 仅 +13%（`bp` 差 +137%）
- repetition 的整个研究**已补到 3 seeds / 98304 shots**（`results/t8/REPETITION_D3_MULTISEED.md`）：换候选集 `bp_osd_cs0 → bp_osd_cs4` 是 **−0.00279 ± 0.00012**（z=−12.23，主结论更硬）；但单 seed 那句「DEM 先验与学习先验在 λ=4 打平（p=0.53）」**要撤回**——多种子下为 **+0.00055 ± 0.00043**（逐 seed +0.00006/+0.00140/+0.00018），正确说法是「**两者在种子噪声内不可区分**」；表面码上学习先验仍有 -24% 增量（单 seed，方向与 repetition 相反，说明 λ=4 的先验之争是配置依赖的）
- λ 扫描即 README 7.2 的「top-k 候选规模」消融：表面码单调，repetition 非单调（λ=4 最优）
- **d=7 上换候选集的收益，按模型 seed 复核后要改写**（3 个**模型 seed** × 1024 shots，`results/t8/D7_MODEL_SEEDS.md`；只换测试集的旧口径见 `D7_MULTISEED.md`）：OSD-0 相对 `bp_gnn` 在 p=0.003/0.005/0.008 上恶化 **+43.0%±14.0% / +34.7%±12.2% / +15.8%±2.4%**（3 个 seed 全部同号）；OSD-CS 把 OSD-0 的伤害修回 **−41.7%±3.8% / −26.2%±1.1% / −14.9%±1.8%**；但 CS 相对 `bp_gnn` 的**净**增益只有 p=0.003 有方向（−15.7%±13.3%，n.s.），p≥0.005 归零（−0.4%±9.8% / −1.5%±1.8%）。叠加后 `bp` → `bp_gnn_osd_cs4` 为 **−44.0% / −27.2% / −13.4%**（±11.4/6.9/5.6）。**旧口径的 −34.9%/−11.6%/−1.9%（cs4 vs bp_gnn）是单一 s1 模型的效应**；p=0.01 只有 s1（3 份测试集，cs4 比 `bp_gnn` 差 +8.4%）
- **T9 图特征消融**：显式坐标/时间特征**冗余**（两种码族、3 seeds 一致）；但只留 DEM 先验会大幅恶化（repetition +133%、表面码 d=3 **+103.4% ± 12.0%**，3 seeds）→ 图结构特征整体不可省。表面码 d=3 的 5 条臂已全部补齐到 3 seeds（98304 shots）：`no_check_features` −4.8%±5.6%、`no_variable_geometry` −3.4%±11.1%、`no_edge_degree` +5.1%±4.3% 都在噪声内；`no_check_geometry` −15.1%±8.5%（逐 seed 同号、t≈1.8，未达显著）→ 只能说「没有证据表明 check 侧几何列提供可复现收益」。⚠️ 单 seed 曾显示「位置特征有害（−24%）」，多种子复核后不成立（Δ = −24.3% / +2.3% / +14.5%），已按此更正

### M5：工程优化（已完成）

- **向量化 BP**（`src/graph_qec/decoders/bp_engine.py`）：约 **100×** 加速（repetition d=3 205 → 1.9 µs/shot；表面码 d=3 18.5 ms → 0.54 ms/shot），使 d=5/d=7 扫描在 CPU 上可行；实现规范与等价性保证见 `docs/BP_IMPLEMENTATION.md`
- **GNN 动态 int8 量化**：权重压缩 3.72×、精度无损、CPU 无加速；量化后 GNN 前向成为管线瓶颈（这也是交付清单中 T5 的动机）
- **学习后验接入 MWPM（保 Stim 分解 + 相对重加权）**：`mwpm_rebuilt` 与零强度相对重加权都与基线逐 shot 一致，说明「保结构 + 保尺度换概率」零副作用；而直接重建 DEM（丢失 `^` 分解）会让 MWPM 从 455 退化到 588，定量说明分解必须保留。学习后验接 MWPM **无 LER 收益**（码容量 455 → 最好 451、满强度 498；线路级 64 → 最好 63、满强度 91），同配置下学习先验接 BP 仍有 -17%——即「逐机制边际在 BP 里能兑现、在 MWPM 边权里兑现不了」
- 产出：`results/m5/`、`docs/M5_ENGINEERING.md`、`docs/M5_DECOMPOSED_MWPM.md`、`docs/BP_IMPLEMENTATION.md`

- **噪声率轴上 d=5 出现低端拐点**：−37.4%（p=0.002）→ **−43.4%（p=0.003，峰值）** → −37.1% → −32.8% → −25.4%；d=7 单调下降（−38.2% → −32.6% → −25.1% → −13.4% → −9.9%，峰值落在区间下沿）
- **OSD-0 在全部 10 个点上都比不开更差**（`bp_osd` 差 +10.4% ~ +60.5%，`bp_gnn_osd` 差 +18.0% ~ +48.7%）→ 再次指向 T8 的候选集结论
- **d=7 上换候选集（OSD-CS）按模型 seed 复核**（3 个模型 seed × 1024 shots，`results/t8/D7_MODEL_SEEDS.md`）：OSD-0 相对 `bp_gnn` 恶化 +43.0%±14.0% / +34.7%±12.2% / +15.8%±2.4%，CS 把伤害修回 −41.7%±3.8% / −26.2%±1.1% / −14.9%±1.8%；但 CS 相对 `bp_gnn` 的净增益只有 p=0.003 有方向（−15.7%±13.3%，n.s.），p≥0.005 归零。`bp` → `bp_gnn_osd_cs4` 仍是 −44.0% / −27.2% / −13.4%
- **阈值（T7）**：MWPM 线路级 **0.005 < p_th < 0.008**；BP 系线路级 **p_th < 0.003**（0.003-0.01 内始终 d=3 更优）。**所有 30 个线路级点都在阈值之上**，这是"d=7 比 d=5 差"的主因，而非解码器变弱
- **同 p 下 d=5 的增益几乎都高于 d=7**（唯一例外是 p=0.002：−37.4% vs −38.2%）→ "码距越大增益越大"在 d>5 之后失效

## 14. 风险与应对

| 风险 | 应对 |
|---|---|
| 神经解码器无法超过经典基线 | 以精度、延迟和内存的 Pareto 改进为目标；明确报告适用区间 |
| 端到端训练不稳定 | 先完成 BP 重加权和候选排序，再尝试端到端模型 |
| 模型无法外推到更大码距 | 分析局部性、图结构和噪声归一化，并明确报告失败边界 |
| HGP 码阈值较低、仿真成本高 | 先从小规模结构化码和 code-capacity 模型开始 |
| OSD 后处理成为延迟瓶颈 | 使用候选剪枝、稀疏矩阵和并行批处理优化 |
| 统计功效不足 | 每结论不少于 3 个 seed，表格显式标注 shots 与 seed 数 |
